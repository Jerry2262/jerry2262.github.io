# CLAUDE.md

## What this is

A static, no-build personal site hosted on GitHub Pages at `jerry2262.github.io`. The repo doubles as a toy-project portal: the homepage links to independent toy projects, each living in its own directory under `apps/`. There is no package manager, bundler, framework, or test runner — every project is plain HTML/CSS/JS served as static files.

## Commands

There is no build or test step. To develop, open files directly in a browser, or serve the repo root:

```bash
python3 -m http.server 8000   # then visit http://localhost:8000/
```

The one tooling script is the secret-page encryptor: `node scripts/encrypt-secret.js --help` (usage, KDF params, and safety checks are all in the script).

## Architecture

### Homepage as entry, apps as the body

`index.html` + `styles.css` form the landing page. Apps are linked as cards in `.feature-grid`; the toys row adds a `.toys-grid` modifier so its column count (6) can differ from the projects row (5). When adding an app: create `apps/<name>/` with its own `index.html` (+ `style.css`/`game.js` as needed), then add a card in `index.html`. Keep each grid's column count in `styles.css` matching its number of cards, and note the mid-width breakpoint that drops both to 2 columns — adjust when adding/removing cards.

Each app is fully self-contained (own HTML, CSS, JS) with no shared runtime; they link back to the homepage via `../../index.html`.

### Subpath repos

Some homepage links (e.g. `cycle/`) point to OTHER GitHub repos on the same account: GitHub Pages deploys each as a project site at `jerry2262.github.io/<repo-name>/`, and the homepage links to that path. Those paths are intentionally NOT directories in this repo — never create matching directories here, they would shadow the deployed sites. The links only resolve on the deployed domain; a local dev server 404s on them, which is expected.

### Secret app (encrypted page pattern)

The secret app ships only ciphertext and decrypts at runtime. Two constraints: `apps/secret/private/` is local-only — never commit it; `apps/secret/payload.js` is generated by the encryptor, not hand-edited.

### Texas Hold'em AI provider seam

Engine/UI/AI are separated per `apps/texas-holdem/INTERFACE.md`. When changing AI behavior, implement against that provider contract — do not couple AI logic into `app.js`.
